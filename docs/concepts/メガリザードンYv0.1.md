# メガリザードンYv0.1 選出ルール

チーム本体: `メガリザードンYv0.1.txt`（6体）。
本ドキュメントは選出の判断基準を厳密化したもので、ダメージ値はすべて
Champions仕様（Lv50・個体値31・能力ポイント32上限）で計算した概算。

## 1. 前提と制約

- 形式はダブルバトル（6体→4体選出、2体先発）
- メガ枠は **メガリザードンY のみ**（他にメガストーンなし）
- 天候は **ひでり**（メガシンカ時に発動）
- テラスタル・ダイマックスは存在しない
- 持ち物の重複なし（リザードナイトＹ／きあいのタスキ／いのちのたま／たべのこし／きせきのタネ／こうかくレンズ）

## 3. 相手PTを見たチェックリスト（この順で判定する）

1. **相手のメガはどれか**（1体）→ その駒を落とす手段を最初に確保する
2. **いわ技使い**（ガブリアス／バンギラス／プテラ／メガメタグロス／ドドゲザン／ルカリオ／メガバンギラス）はいるか → いるならリザードンYを先発に出さない
3. **全体技**（ハイパーボイス／ワイドフォース／いわなだれ／ねっぷう／マジカルシャイン）はあるか → あるならラグラージを入れる
4. **トリックルーム**（イエッサン♀・♂／リキキリン／グレンアルマ／メガサーナイト／ブリムオン）はいるか → いるならプテラを先発
5. **あく技**（ドドゲザン／ガオガエン／メガバンギラス／バンギラス／メガグソクムシャ／マニューラ／ブリジュラス）はいるか → いるならサーフゴーを後発へ。マニューラは素早さ145でサーフゴー(136)より速く、あく技2倍を先手で取るため、サーフゴーをマニューラに当てない。ブリジュラスはバークアウト（特攻1段階ダウン・相手全体）を持つ
6. **かくとう技**（オオニューラ／ルカリオ／メガムクホーク）はいるか → いるならヒスイウインディを先発に出さない
7. **相手のS操作**（おいかぜ／こごえるかぜ）はあるか → あるならプテラのおいかぜで対抗
8. **メガゲンガー**（かげふみで交代封じ）はいるか → いるならサーフゴーを選出して対面を作る（サイコキネシス確定1）
9. **ドラパルト**（素早さ162）はいるか → いるならプテラで追い風を張り、こおり技で削る
10. **キラフロル**（岩/毒・地面4倍）はいるか → いるならラグラージのだいちのちから（確定1）
11. **ブリジュラス**はいるか → いるなら **メガリザードンYのウェザーボール（晴れ）＋ラグラージのだいちのちから** の2枚で処理する。特防無振りならウェザーボール138.9-164.1%・だいちのちから107.8-126.9%でどちらも確定1、特防特化なら77.7-91.9%・60.9-73.1%でどちらも2発（詳細は12章）
12. **雨要員（ニョロトノ／ペリッパー）＋でんき高火力（エレクトロビーム）**が並ぶか → 雨下のエレクトロビームはメガリザードンYに181.9-214.2%（確定1）。ラグラージを選出し、ブリジュラスを先に処理する
13. **オオニューラ＋サイコメイカー（イエッサン(メス)など）**が並ぶか → いるならサーフゴーを選出（サイコキネシス4倍・確定1）。**サイコフィールド下でオオニューラがサイコシードを使うと、かるわざで素早さが2倍（172→344）になり、プテラS200でも先手を取れない**。プテラのちょうはつでトリックルームを止める計画は捨てる。ゴリランダーのグラスメイカーでフィールドを上書きできればサイコシードは発動しない（先発同時登場時のフィールドの奪い合いは未検証）
14. **ドドゲザン（ふいうち）がいるか** → いるなら**トリル中に落とす**。そうだいしょうで味方の瀕死1体ごとに火力+10%なので終盤に残すほど危険。ふいうちは優先度+1で「相手が攻撃技を選ばない／先に動く」と失敗するので、まもる・しんそくで空振りさせられる。削れた駒を最終盤に対面させない

## 5.5 敗戦からの鉄則（2026/10/09 負け5戦の振り返り）

実戦の負け5戦を振り返った結果、**3戦はこのコンセプトの既存ルールを守らずに選出したこと**が敗因。選出前に第3章のチェックリストを1から順に必ず回すこと。

- **対戦5（ガブリアス入り）**: ガブリアスがいるのにリザードンYを選出して敗北。ガブリアスのいわなだれはリザードンYに151-178%で確定1。**ガブリアスを見たらリザードンYは出さない**（後発はサーフゴー＋ゴリランダー）。
- **対戦6（オオニューラ入り）**: オオニューラがいるのにサーフゴーを未選出で敗北。オオニューラはサーフゴーのサイコキネシス確定1（177-209%）。**オオニューラを見たらサーフゴーは必ず選出**。
- **対戦10（ボーマンダ入り）**: ボーマンダがいるのにプテラを未選出で敗北。**ボーマンダを見たら「ラグラージ＋プテラ」先発**が基本。

**複合キー駒の優先順位**

- オオニューラ＋ガオガエンが両方いる → **サーフゴー優先**（オオニューラをサイコキネシス確定1で落とす）。ガオガエンのあく技はまもる・ワイドガードでしのぐ。
- ガブリアス＋ガオガエンが両方いる → ガブリアス優先で**リザードンYを外す**。ガオガエンはラグラージのだいちのちから（98.8%・2発）で削る。
- キラフロル＋ヤバソチャが両方いる → ラグラージは出す（だいちのちからでキラフロル確定1）が、**ヤバソチャの草技に注意**。横のサーフゴー／ヒスイウインディでヤバソチャを先に処理する。
- リザードンYの炎が通らない相手（ガオガエン・キラフロル・たいねつヤバソチャ）には、思い切って**リザードンYを外し**サーフゴー・ラグラージを優先する。

### この動画から追加するルール

3. **相手にリザードンがいるならゴリランダーを出さない**。くさ0.25倍・じめん無効で、被弾はねっぷう確定1。

### 推奨選出（この2戦の相手に対する修正案）

## 13. 26/11/01 動画（ydxU93k9a24）の負け1戦からの追記

相手は **イエッサン(メス)＋オオニューラ先発のトリックルーム軸**。自分の選出は先発サーフゴー＋プテラ、後発ヒスイウインディ＋メガリザードンY（ラグラージ・ゴリランダーは未選出）。9ターンで負け。

### 敗因1: ちょうはつは選んでいたが、サイコシード＋かるわざでオオニューラに先手を取られた

1ターン目は**プテラでちょうはつを選択していた**。それでも成立しなかった。イエッサン(メス)のサイコメイカーでサイコフィールドが展開され、オオニューラが**サイコシード**を使用 → フィールド条件を満たしてサイコシードが消費され、持ち物が無くなったことで**かるわざ**が発動して素早さが2倍になった。

- オオニューラの素早さ実数値は172（AS32・いじっぱり想定）。かるわざで**344**相当になり、プテラの200を大きく上回る。
- 先手を取ったインファイトがプテラに**160-189（101.9-120.4%）**で確定1。プテラの持ち物はこうかくレンズでタスキが無いため耐えられない。

つまり「プテラのちょうはつでトリルを止める」は、**オオニューラ＋サイコメイカー＋サイコシードが揃うと成立しない**。ちょうはつが機能するのは、相手の変化技役がプテラ（S200）より遅いときだけ。
