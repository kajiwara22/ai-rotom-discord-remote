## ステータス

<!--
意思決定の状態を示します。以下の4つのいずれかを記載してください。

  - 検討中       : まだ結論が固まっていない、書きかけ・検討中の段階
  - 採用         : 決定が確定し、有効になっている状態
  - 見送り       : 検討したが、採用しなかった状態（＝一度も採用していない）
  - 差し替え済み : かつては採用していたが、別の ADR に置き換えられた状態
                   （例: 差し替え済み（ADR-0012 にて置き換え））

【重要1】一度「採用」した決定が後で覆る場合、この ADR を書き換えるのでは
なく、新しい ADR を作成してください。そのうえで、古い ADR のステータスを
「差し替え済み」に変更し、双方の ADR から相互に参照（リンク）を張って、
意思決定の経緯をたどれるようにします。

【重要2】「見送り」と「差し替え済み」は必ず使い分けてください。
「見送り」は一度も採用しなかった案、「差し替え済み」はかつて採用していた案
です。この違いが、後から履歴を振り返るときの価値になります。
-->
